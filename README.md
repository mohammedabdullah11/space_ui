## 🌠 About The Project

**Space App** is a space exploration application designed to bring the beauty of our solar system to your fingertips.

The application combines a visually impressive user interface with interactive 3D planet presentations, allowing users to explore planets and discover fascinating information about them through an engaging and immersive experience.

The main focus of this project is to deliver an exceptional **UI/UX experience**, where visual quality, smooth interactions, and elegant design work together to create an application that feels modern, fluid, and enjoyable to use.

## ✨ Features

* 🪐 **3D Planet Visualization** — Explore planets through immersive three-dimensional presentations.
* 🎨 **Premium User Interface** — A modern, visually appealing design crafted to make every screen feel polished and engaging.
* 🌌 **Space-Inspired Design** — A captivating visual experience inspired by the beauty and mystery of the universe.
* 🚀 **Smooth Navigation** — Fluid transitions and seamless movement throughout the application.
* 📚 **Planet Information** — Discover interesting facts and information about the planets.
* 📱 **Mobile Experience** — Designed to provide an engaging experience on Android devices.
* 💫 **UI/UX Focused** — Careful attention to visual hierarchy, layout, spacing, and the overall user experience.

## 🎨 UI/UX — The Heart of the Experience

One of the biggest highlights of Space App is its **user interface and overall visual experience**.

The goal was not simply to display information about planets, but to present that information in a visually attractive and immersive way.

The application focuses on:

* **Visual Excellence:** A polished interface with a distinctive space-inspired aesthetic.
* **Smooth Interactions:** An emphasis on fluid navigation and a comfortable browsing experience.
* **Immersive Presentation:** Three-dimensional planet visuals that make exploring the solar system more engaging.
* **Clean Layouts:** Well-organized content that makes planet information easy to explore.
* **Attention to Detail:** A consistent visual style designed to make the application feel cohesive and professional.

> The vision behind Space App is simple: combine beautiful design, smooth interactions, and 3D planetary visuals to create a memorable space exploration experience.

## 🚀 Getting Started

Follow these steps to run Space App locally.

### Prerequisites

Make sure you have the following installed:

* [Flutter SDK](https://docs.flutter.dev/get-started/install)
* [Android Studio](https://developer.android.com/studio)
* Git

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd space_app
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

Connect an Android device or start an emulator, then run:

```bash
flutter run
```
